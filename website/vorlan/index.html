VORLAN: a home server that runs without the cloud

VORLAN is an offline-first home server and network manager built by DSRF Softech Studios. It brings file storage, a private vault, notes, live camera feeds and an AI assistant onto your own network.

The problem

Why we built it

Most tools for storing files, watching cameras or asking an AI a question sit behind a cloud account. Your photos, footage and conversations end up on someone else’s servers, and everything stops when the connection does.

VORLAN works the other way round. You sign in once on your PC, then open the same dashboard from your phone or any other device on the network.

Features

What we built

For everyone on the network

  • AI assistant that answers offline, with saved conversations and streamed replies
  • File manager with search, copy, cut, paste and rename
  • Shared media storage for photos, video and documents
  • A PIN-locked personal vault for private files and notes

Cameras and devices

  • Live view from any IP camera by its stream address
  • A connected-devices page for each account
  • QR-code device onboarding, currently in progress
  • Customizable dashboard with wallpapers, tiles and light or dark themes

For the administrator

  • A desktop of draggable windows: Resource Monitor, Storage Manager, Task Manager, Log Center, Services, Network and Support
  • Live charts with 30 days of history
  • Accounts with roles, and an audit log

Under the hood

How it is built

VORLAN is a React front end talking to an Express back end with a SQLite database. Authentication, storage and the AI assistant all run on the same machine. The assistant uses a local model served by Ollama, so it works with the internet unplugged.

A one-click Linux installer sets up Node.js, Ollama with its model and the wireless hotspot tooling for phone access, then adds VORLAN to the application menu.

Status

Where it stands

VORLAN is in active development toward version 1.0. The source code is currently private, so there is no public download yet. If you want early access, or a similar self-hosted system built for your own needs, get in touch.
